# Executable counterexamples and limits

These are prototype tests against design-visible cases. They do not consume or certify a held-out cohort, and they do not mark K06/K07 or domain queue items complete.

| Counterexample | Executable tests | Expected behavior | Exact coverage limit |
|---|---|---|---|
| CE1 Vacuous profile | `test_requester_cannot_select_vacuous_profile_or_validator`; `test_omitted_native_effect_gate_is_a_detected_adapter_violation` | Unknown/request-supplied profile rejected; omitted effect gate recorded as a contract violation with UNKNOWN. | Compiled-in packs are trusted code; an attacker controlling arbitrary runtime code is not sandboxed. |
| CE2 Approval/revision drift | `test_approval_cannot_follow_new_revision`; `test_every_authority_binding_is_checked_even_when_issuer_signed` | No new revision, tenant, principal, destination, effect or profile can inherit another grant. | Local issuer/principal only; no enterprise delegation or approval quorum. |
| CE3 Timeout then provider substitution | `test_effect_then_exception_remains_owned_unknown`; `test_new_revision_or_domain_cannot_amplify_existing_effect`; `test_replaced_destination_cannot_inherit_authority` | Possible effect retained; replay/substitution refused; new destination identity rejected. | Local effect/account pin and repeatability only. Two independent remote providers accepting a duplicated irreversible effect were not exercised. |
| CE4 Effect before journal / crash | Process tests before effect, during SQLite DDL, after file stage sync and after committed effect; `test_failed_journal_commit_prevents_domain_mutation` | No dispatch after failed claim commit; recoverable UNKNOWN before observation; native rollback/marker evidence or file PARTIAL as justified. | Process loss only; no power-cut, disk-loss or dishonest-storage test. |
| CE5 Permanent observation gap | `test_permanent_observation_gap_is_unknown_not_success`; `test_unknown_retirement_requires_horizon_custody_and_separate_authority`; `test_late_observation_preserves_unknown_retirement_history` | UNKNOWN stays owned; authorized retirement retains uncertainty; late observation appends history; no blind repeat. | Explicit owner retirement; no routing service, notification or automatic closure timer. |
| CE6 Takeover race / stale worker | `test_manual_takeover_cannot_overlap_live_worker`; `test_stale_released_runtime_cannot_resume_effect` | A live local owner blocks takeover; a released runtime cannot execute; restart does not replay. | Fail-closed refusal of overlap, not distributed lease/fencing or active forced handoff. |
| CE7 False outcome | Adapter return/error tests; SQLite wrong/default/missing-marker/marker-revision tests; staged-file crash | Acknowledgment/exception/marker alone never verifies an unsupported postcondition. Domain observation preserves drift or partial state. | Synthetic native fixtures, not every connector's actual external outcome semantics. |
| CE8 Current read / stale write race | `test_current_read_stale_write_race_is_refused_inside_file_boundary`; `test_sqlite_current_read_and_write_are_in_one_destination_transaction`; stale-state tests | File re-read rejects observed intervening drift; native SQLite transaction excludes concurrent writer. | File writers must cooperate with the lock; no universal filesystem CAS against arbitrary OS-owner writes. SQLite path replacement by a privileged owner is excluded. |

Other executed cases include exact expiry boundaries, future authority, revocation before and after admission, profile rollout while waiting, state-witness expiry, clock regression, gate reuse, typed SQL injection/default literals, wrong actor/tenant, Unicode binding, missing/corrupt journal, configuration drift, key-offline execution and separate-process CLI flow.

An adapter implementation defect is not automatically a kernel invariant failure. An accepted trace requiring a new shared rule would be a normative contract counterexample and must be recorded as such during future frozen testing. This prototype remains unfrozen; no score is calculated.
