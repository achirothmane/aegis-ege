# StateLatch v0.2.0-prealpha

StateLatch is an experimental evidence-gated runtime-assurance layer for autonomous Kubernetes changes.

This release marks the point where the current node-drain safety thesis has been tested through three layers:

```text
synthetic falsification
→ live KinD adversarial testing
→ source-backed Kubernetes incident replay
```

## Highlights

### Continuous state invalidation

Kubernetes watch events can invalidate assumptions before a new execution request arrives.

### Transitive dependency graph

A change in a dependency such as a PodDisruptionBudget can invalidate a higher-level assumption such as “node drain is safe,” even when the target Node did not change.

### Independent evidence

Prometheus-compatible HTTP evidence can be required alongside Kubernetes evidence.

Contradiction produces BLOCK; missing required independent evidence produces ESCALATE.

### Active evidence acquisition

UNKNOWN can trigger a bounded READ_ONLY probe and deterministic re-evaluation.

### Action-sensitive temporal validity

Critical actions can require fresher assumptions than lower-consequence actions.

### State-bound guarded execution

Authorization is bound to the exact observed action/target/state/plan and is revalidated before and during execution.

### Postflight verification

Expected and observed outcomes are compared after execution.

The postflight invariant now also detects unexpected workloads that appear on a drained Node after execution.

## Benchmark evidence

### v1 — 40 synthetic labeled cases

- baseline unsafe ALLOWs: 19
- StateLatch unsafe ALLOWs: 0
- baseline unresolved ALLOWs: 4
- StateLatch unresolved ALLOWs: 0
- safe blocks: 0
- postflight divergence detection: StateLatch 2/2, baseline 0/2

### v2 — 8 live KinD adversarial cases

- baseline unsafe ALLOWs: 3
- StateLatch unsafe ALLOWs: 0
- baseline unresolved-source ALLOWs: 1
- StateLatch unresolved-source ALLOWs: 0
- safe controls preserved: 2/2
- ordinary PDB denial caught by both systems
- postflight divergence: StateLatch 1/1, baseline 0/1

### v3 — source-backed incident replay

Three public Kubernetes incident classes are replayed.

One replay initially falsified StateLatch: a new Pod created with explicit `spec.nodeName` after drain was not detected by the old postflight logic.

The replay failed first, the product was repaired, and the same success criterion then passed.

## Safety posture

Real Kubernetes mutations remain disabled by default.

The experimental mutation path must be explicitly enabled.

This is a **pre-alpha research/prototype release**, not a production-ready replacement for `kubectl drain`.

## Adoption gate

Major new capability work is now paused until external usage evidence passes the thresholds in `ADOPTION.md`.

The project is moving from feature accumulation to adoption testing.
